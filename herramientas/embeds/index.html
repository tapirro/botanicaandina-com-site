Herramientas Gratuitas para tu Sitio Web

Integra herramientas de salud basadas en evidencia científica. Sin registro, sin publicidad, sin costo.

¿Cómo funciona?

  1. Elige la herramienta que necesitas
  2. Haz clic en "Copiar código embed"
  3. Pega el código en tu sitio web (WordPress, HTML, Wix, etc.)
  4. ¡Listo! La herramienta se actualiza automáticamente
